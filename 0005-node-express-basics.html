บทเรียนที่ 5 · ลงมือสร้าง Backend

Node.js + Express: สร้างเซิร์ฟเวอร์ตัวแรก

ใช้เวลาทำประมาณ 25-30 นาที · ต้องมี Node.js ติดตั้งในเครื่อง (เช็คด้วย node -v ใน terminal)

เป้าหมาย · สร้างระบบเงินเดือน/ความปลอดภัยใช้เองที่ ESS

ถึงตอนนี้ทุกอย่างที่ทำมายังอยู่แค่ในเบราว์เซอร์เครื่องเดียว บทนี้จะสร้าง Backend ตัวจริง — โปรแกรมที่รันแยกต่างหาก คอยรอรับคำขอจากฟอร์ม เปิดทางให้ข้อมูลเดินทางไปเก็บที่อื่นได้ในบทถัดๆ ไป

1. โปรเจกต์ Node.js เริ่มต้นด้วย package.json

สร้างโฟลเดอร์ใหม่ (เช่น ess-safety-app) แล้วเปิด terminal ในโฟลเดอร์นั้น พิมพ์:

npm init -y

คำสั่งนี้สร้างไฟล์ package.json — เอกสารกำกับโปรเจกต์ (ชื่อ, เวอร์ชัน, และที่สำคัญคือ รายชื่อ "library" หรือ package ภายนอกที่โปรเจกต์นี้ใช้) เทียบง่ายๆ คือเหมือนไฟล์ config ที่บอกว่าโปรเจกต์นี้ต้องมีอะไรบ้างถึงจะรันได้

2. ติดตั้ง Express

Node.js เปล่าๆ เขียน server ได้แต่ค่อนข้างยาก Express คือ library ที่ทำให้เขียนง่ายขึ้นมาก เป็นตัวที่ใช้กันแพร่หลายที่สุดสำหรับงานนี้: 

npm install express

คำสั่งนี้ดาวน์โหลด Express มาเก็บในโฟลเดอร์ node_modules และบันทึกไว้ใน package.json ว่าโปรเจกต์นี้ต้องใช้ Express

3. เขียน server.js ตัวแรก

const express = require('express');
const app = express();

app.get('/', (req, res) => {
  res.send('เซิร์ฟเวอร์ทำงานแล้ว!');
});

app.listen(3000, () => {
  console.log('เปิดรับคำขอที่ http://localhost:3000');
});

รันด้วย:

node server.js

แล้วเปิดเบราว์เซอร์ไปที่ http://localhost:3000 ควรเห็นข้อความ "เซิร์ฟเวอร์ทำงานแล้ว!" — นี่คือ backend ตัวแรกในชีวิตที่รันจริง!

4. อ่านโค้ดทีละส่วน: route คืออะไร

  • app.get('/', ...) — เมื่อมีคนขอดู (GET) หน้าแรก / ให้ทำตามฟังก์ชันนี้
  • req (request) — ข้อมูลของคำขอที่เข้ามา เช่น ใครส่งมา ส่งอะไรมาด้วย
  • res (response) — เครื่องมือไว้ตอบกลับ เช่น res.send() ส่งข้อความ, res.json() ส่งข้อมูลแบบ JSON
  • app.listen(3000, ...) — เปิดเซิร์ฟเวอร์ให้รอฟังที่ port 3000 (เลขห้องที่ใช้คุยกัน บนเครื่องเดียวกันเปิดได้หลาย port พร้อมกัน)

5. เพิ่ม route รับข้อมูลจากฟอร์ม (POST)

Route แบบ GET ใช้สำหรับ "ขอดู" ส่วน POST ใช้สำหรับ "ส่งข้อมูลเข้าไป" — เพิ่มโค้ดนี้ต่อจาก route เดิม:

app.use(express.json()); // ให้ Express อ่านข้อมูล JSON ที่ส่งมาได้

app.post('/api/reports', (req, res) => {
  console.log('ได้รับรายงาน:', req.body);
  res.json({ success: true, message: 'บันทึกรายงานแล้ว' });
});

express.json() คือ middleware — โค้ดที่ทำงานคั่นกลางก่อนถึง route handler เสมอ หน้าที่ของมันคือแปลงข้อมูล JSON ดิบๆ ที่ส่งมาให้กลายเป็น req.body ที่ใช้งานได้ทันที

แผนภาพ 4 — คำขอไหลผ่าน middleware ก่อนถึง route handler แล้วย้อนกลับเป็น response

ทดสอบ POST โดยยังไม่มีฟอร์ม

ยังไม่ต้องต่อกับฟอร์มจริงในบทนี้ก็ได้ ลองทดสอบด้วยเครื่องมืออย่าง Postman หรือคำสั่ง curl -X POST http://localhost:3000/api/reports -H "Content-Type: application/json" -d '{"reporterName":"May"}' ใน terminal อีกหน้าต่าง (เปิดเซิร์ฟเวอร์ทิ้งไว้ด้วย) แล้วดูว่า terminal ฝั่งเซิร์ฟเวอร์ print ข้อมูลออกมาไหม ติดขั้นตอนไหนถามได้เลย

แหล่งอ้างอิงหลัก

ทดสอบความเข้าใจ

1. โค้ดที่ทำงานคั่นกลางก่อนถึง route handler เสมอ (เช่น แปลง JSON ให้อ่านง่าย) เรียกว่าอะไร?

2. คำขอแบบไหนที่เหมาะกับ "ส่งข้อมูลใหม่เข้าไปให้เซิร์ฟเวอร์เก็บ"?

บทต่อไปจะเรียนอะไร

มี server ที่รับข้อมูลได้แล้ว แต่ยังทดสอบด้วย curl/Postman อยู่ บทเรียนที่ 6 จะเอาฟอร์มจริงจากบทที่ 2-4 มาต่อกับ server ตัวนี้ผ่าน fetch() ให้กด "ส่งรายงาน" แล้วข้อมูลวิ่งไปถึง server จริงๆ
