บทเรียนที่ 2 · ลงมือเขียนโค้ดจริง

เขียน HTML หน้าแรก: ฟอร์มแจ้งเหตุความปลอดภัย

ใช้เวลาทำประมาณ 15-20 นาที · ต้องมีเครื่องเขียนโค้ด (VS Code หรือ Notepad ก็ได้) และเบราว์เซอร์เปิดคู่กัน

เป้าหมาย · สร้างระบบเงินเดือน/ความปลอดภัยใช้เองที่ ESS

บทที่แล้วเราเห็นภาพรวมว่าเว็บแอปมี 3 ส่วน วันนี้จะลงมือสร้าง Frontend ส่วนแรก จริงๆ — หน้าฟอร์มแจ้งเหตุความปลอดภัยที่พนักงานจะใช้กรอกจริง ยังไม่ต้องมี backend หรือ database (กด "ส่ง" แล้วจะยังไม่มีอะไรเกิดขึ้น — นั่นเป็นเรื่องของบทถัดไป) เป้าหมายบทนี้คือ เห็นหน้าฟอร์มที่เขียนเองทั้งหน้าให้ได้ก่อน

1. โครงหลักของทุกไฟล์ HTML

ไฟล์ HTML ทุกไฟล์เริ่มด้วยโครงเดียวกันเสมอ ลองสร้างไฟล์ชื่อ report.html แล้วพิมพ์ตามนี้: 

<!DOCTYPE html>
<html lang="th">
<head>
  <meta charset="UTF-8">
  <title>แจ้งเหตุความปลอดภัย</title>
</head>
<body>
  <!-- เนื้อหาที่คนเห็นจะอยู่ตรงนี้ -->
</body>
</html>
  • <!DOCTYPE html> — บอกเบราว์เซอร์ว่านี่คือเอกสาร HTML5
  • <head> — ข้อมูลเบื้องหลัง (ชื่อแท็บ, การเชื่อมไฟล์อื่น) ไม่แสดงบนหน้าจอ
  • <body> — ทุกอย่างที่คนเห็นจริงอยู่ในนี้ทั้งหมด

เปิดไฟล์นี้ด้วยเบราว์เซอร์ (ดับเบิลคลิก หรือลากเข้าไปในเบราว์เซอร์) จะเห็นหน้าว่างเปล่า — ถูกต้องแล้ว เพราะยังไม่มีอะไรใน <body>

2. องค์ประกอบของฟอร์ม

ฟอร์มทุกฟอร์มบนเว็บ ประกอบด้วย tag หลักๆ ไม่กี่ตัว:

  • <form> — กล่องที่ครอบทุกฟิลด์ของฟอร์มไว้ด้วยกัน
  • <label> — ป้ายกำกับบอกว่าฟิลด์นี้คือช่องกรอกอะไร
  • <input> — ช่องกรอกข้อมูลบรรทัดเดียว มีหลาย type เช่น text, date, radio
  • <textarea> — ช่องกรอกข้อความยาวหลายบรรทัด
  • <select> + <option> — เมนูดรอปดาวน์ให้เลือก
  • <button> — ปุ่มกด (เช่น ปุ่มส่งฟอร์ม)

3. ประกอบร่างเป็นฟอร์มแจ้งเหตุจริง

ค่อยๆ เพิ่มทีละส่วนใน <body> ตามนี้:

3.1 หัวข้อและชื่อผู้แจ้ง

<h1>แบบฟอร์มแจ้งเหตุความปลอดภัย</h1>

<form>
  <label for="reporter-name">ชื่อผู้แจ้ง</label>
  <input type="text" id="reporter-name" name="reporterName" required>
</form>

สังเกต for="reporter-name" กับ id="reporter-name" ต้องตรงกัน — นี่คือวิธีบอกเบราว์เซอร์ว่า label นี้เป็นของ input ตัวไหน (กดที่ label แล้ว cursor จะกระโดดไปที่ช่องกรอกเลย) ส่วน required คือสั่งให้เบราว์เซอร์บังคับกรอกก่อนส่งได้

3.2 วันที่และสถานที่เกิดเหตุ

<label for="incident-date">วันที่เกิดเหตุ</label>
<input type="date" id="incident-date" name="incidentDate" required>

<label for="location">สถานที่เกิดเหตุ</label>
<input type="text" id="location" name="location" placeholder="เช่น อาคาร A ชั้น 2">

placeholder คือข้อความจางๆ ในช่องว่าง ใช้เป็นตัวอย่าง ไม่ใช่ค่าจริงที่จะถูกส่งไป

3.3 ประเภทเหตุ (dropdown) และระดับความรุนแรง (radio)

<label for="incident-type">ประเภทเหตุ</label>
<select id="incident-type" name="incidentType">
  <option value="near-miss">เกือบเกิดอุบัติเหตุ</option>
  <option value="injury">มีผู้บาดเจ็บ</option>
  <option value="equipment">อุปกรณ์เสียหาย</option>
</select>

<fieldset>
  <legend>ระดับความรุนแรง</legend>
  <label><input type="radio" name="severity" value="low"> ต่ำ</label>
  <label><input type="radio" name="severity" value="medium"> ปานกลาง</label>
  <label><input type="radio" name="severity" value="high"> สูง</label>
</fieldset>

<fieldset>/<legend> ใช้จัดกลุ่ม radio ที่เกี่ยวข้องกันให้เห็นเป็นชุดเดียว — สังเกตว่า radio ทั้งสามตัวใช้ name="severity" เหมือนกัน นั่นคือสิ่งที่ทำให้เลือกได้ทีละตัว

3.4 รายละเอียดเหตุการณ์และปุ่มส่ง

<label for="details">รายละเอียดเหตุการณ์</label>
<textarea id="details" name="details" rows="4"></textarea>

<button type="submit">ส่งรายงาน</button>

ลองทำเอง ก่อนดูของจริง

ลองต่อโค้ดทั้ง 4 ส่วนข้างบนเข้าด้วยกันในไฟล์ report.html ของตัวเองก่อน แล้วเปิดดูผลลัพธ์ในเบราว์เซอร์ ถ้าติดตรงไหน หรืออยากรู้ว่าทำไม HTML เพียวๆ ถึงหน้าตาดูรกๆ ไม่เหมือนเว็บจริง — ถามได้เลย (คำตอบสั้นๆ คือ: ยังไม่มี CSS ตกแต่ง ซึ่งเป็นบทถัดไป)

ผลลัพธ์ที่ควรได้ (ลองเทียบกับของคุณ)

แบบฟอร์มแจ้งเหตุความปลอดภัย

ระดับความรุนแรง

(ปุ่มนี้กดได้แต่ยังไม่ส่งไปไหน — ต้องมี backend ก่อน ซึ่งเป็นบทถัดไป)

ตัวอย่างที่ 1 — ฟอร์มเดียวกัน แต่ยังไม่ใส่ CSS ตกแต่ง (หน้าตาแบบ HTML ล้วนๆ)

แหล่งอ้างอิงหลัก

ทดสอบความเข้าใจ

1. tag ที่ใช้เขียนป้ายกำกับให้ input (กดแล้ว cursor กระโดดไปที่ช่องกรอก) ชื่อว่าอะไร?

<____ for="reporter-name">ชื่อผู้แจ้ง</____>

2. ช่องกรอกข้อความยาวหลายบรรทัด (เช่น รายละเอียดเหตุการณ์) ใช้ tag ชื่อว่าอะไร?

<____ id="details" rows="4"></____>

3. tag ที่ครอบฟิลด์ทั้งหมดของฟอร์มไว้ด้วยกันในหนึ่งเดียว ชื่อว่าอะไร?

<____> ... ฟิลด์ทั้งหมด ... </____>
