CSS พื้นฐาน: ตกแต่งฟอร์มให้ใช้งานง่ายขึ้น

ใช้เวลาทำประมาณ 20 นาที · ต่อยอดจากไฟล์ report.html ในบทที่ 2

เป้าหมาย · สร้างระบบเงินเดือน/ความปลอดภัยใช้เองที่ ESS

ฟอร์มจากบทที่แล้วใช้งานได้ แต่หน้าตายังเป็นค่าเริ่มต้นของเบราว์เซอร์ล้วนๆ — ทุก input ชิดกัน ไม่มีสี ไม่มีระยะห่าง วันนี้เราจะใช้ CSS แต่งให้มันดูเป็นระบบงานจริง

1. CSS คือชุดกฎ "เลือกอะไร แล้วแต่งยังไง"

ทุกกฎ CSS มีรูปแบบเดียวกันเสมอ:

selector {
  property: value;
}

เช่น label { color: #52696c; } แปลว่า "ทุก <label> ในหน้านี้ ให้ใช้สีนี้" วิธีใส่ CSS เข้าไฟล์มี 3 แบบ แต่ที่ควรใช้จริงคือ ไฟล์ .css แยกต่างหาก แล้วเชื่อมเข้า HTML ด้วย <link> ในส่วน <head>: 

<head>
  <link rel="stylesheet" href="style.css">
</head>

ข้อดีคือไฟล์เดียวใช้กับหลายหน้าเว็บได้ (บทหลังๆ เราจะมีหลายหน้า เช่น หน้าฟอร์ม กับหน้ารายการรายงาน ใช้ style.css ไฟล์เดียวกันทั้งคู่)

2. เลือกเป้าหมายด้วย selector 3 แบบหลัก

  • label — เลือกตาม ชื่อ tag ทุกตัวในหน้าโดนหมด
  • .field — เลือกตาม class (จุดที่ใส่ class="field" ใน HTML) ใช้ซ้ำได้หลายจุด
  • #reporter-name — เลือกตาม id เจาะจงจุดเดียวในหน้า

กฎมือใหม่ที่ใช้ได้จริง: ใช้ class เป็นหลัก เพราะใช้ซ้ำได้ เก็บ id ไว้สำหรับเชื่อมกับ <label for="..."> หรือให้ JavaScript หาเจอ (บทหน้า) เท่านั้น

3. Box Model — ทุก element คือกล่องซ้อนกัน

element ทุกตัวบนหน้าเว็บ ถูกมองเป็น "กล่อง" ที่มี 4 ชั้นซ้อนกันจากในสุดไปนอกสุด:

แผนภาพ 2 — content อยู่ในสุด ล้อมด้วย padding, border, margin ตามลำดับ

padding คือช่องว่างด้านในกรอบ (ระหว่างเนื้อหากับเส้นขอบ) ส่วน margin คือช่องว่างด้านนอกกรอบ (ระยะห่างจาก element ข้างเคียง) — สับสนสองอันนี้บ่อยที่สุดตอนเริ่มต้น

4. Flexbox — จัดฟิลด์ฟอร์มให้เรียงกันสวยๆ

ปกติ element จะเรียงต่อกันเรื่อยๆ ตามธรรมชาติ ถ้าอยากจัดเป็นแถวหรือคอลัมน์ที่มีระยะห่างสม่ำเสมอ ใช้ display: flex กับ container ที่ครอบกลุ่มนั้น: 

.form-field {
  display: flex;
  flex-direction: column; /* เรียงจากบนลงล่าง */
  gap: 6px;               /* ระยะห่างระหว่างลูกแต่ละตัว */
}

gap คือคำสั่งที่คุ้มค่าที่สุดใน flexbox — ทดแทนการไล่ตั้ง margin ทีละจุดได้เกือบหมด

5. ใส่ CSS จริงให้ report.html

สร้างไฟล์ style.css ข้างๆ report.html แล้วใส่:

body {
  font-family: sans-serif;
  max-width: 480px;
  margin: 40px auto;
  background: #f4f6f5;
  color: #1c2b2e;
}

.form-field {
  display: flex;
  flex-direction: column;
  gap: 6px;
  margin-bottom: 16px;
}

.form-field label {
  font-size: 14px;
  font-weight: 600;
  color: #52696c;
}

.form-field input,
.form-field select,
.form-field textarea {
  padding: 8px 10px;
  border: 1px solid #cddad8;
  border-radius: 4px;
  font-size: 15px;
}

button {
  background: #c8790f;
  color: white;
  border: none;
  padding: 10px 20px;
  border-radius: 4px;
  font-size: 15px;
  cursor: pointer;
}

แล้วห่อแต่ละ label+input ในบทที่แล้วด้วย <div class="form-field">...</div> เพื่อให้ selector .form-field จับกลุ่มได้ถูก — เปิดเบราว์เซอร์ดูผลลัพธ์ ควรเห็นความต่างชัดเจนทันที

ลองปรับสีเป็นของตัวเอง

ลองเปลี่ยนค่าสี (เช่น #c8790f) เป็นสีอื่นที่ชอบ แล้วดูว่าปุ่มเปลี่ยนสีตามจริงไหม — วิธีที่เร็วที่สุดในการเข้าใจ CSS คือลองแก้ค่าแล้วดูผลทันที ถ้าอยากรู้จักสีเป็นระบบมากขึ้น (เช่น ทำไมใช้ตัวเลขฐาน 16 แบบ #c8790f) ถามได้เลย
